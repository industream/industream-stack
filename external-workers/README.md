# External Workers

Place your custom worker directories here. Each worker must contain an `industream.yaml` manifest.

## Usage

```bash
# Add a worker
industream worker add ./my-worker/

# List installed workers
industream worker list

# Remove a worker
industream worker remove my-worker
```

## Structure

```
external-workers/
├── my-custom-worker/
│   ├── industream.yaml          # Worker manifest (required)
│   ├── docker-stack.external.yml # Auto-generated by CLI
│   └── image.tar.gz             # Optional: pre-built image
└── another-worker/
    └── industream.yaml
```

Workers placed here are automatically included in `industream deploy`.

See `industream-cli/examples/simple-worker/` for a minimal example.
